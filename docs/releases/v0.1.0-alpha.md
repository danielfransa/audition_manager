# Audition Manager v0.1.0-alpha

## Português

Primeira pré-release pública para validação. O pacote portátil Windows inclui a
aplicação, runtime NAM e exemplos rastreados em `samples/`.

Disponível nesta versão:

- audição offline de IRs e capturas NAM A2 Full/Lite e legadas compatíveis;
- cadeia `DI → NAM → IR` com bypasses independentes;
- bibliotecas, busca, favoritos, estrelas, notas e preferências persistentes;
- ganho NAM, ganho geral, medidor de pico, transporte e Loop;
- exportação organizada de capturas e IRs favoritos;
- interface em Português e Inglês;
- pacote Windows testado pelo mantenedor, ainda sem assinatura digital.

Extraia o ZIP inteiro antes de executar `AuditionManager.exe`. Esta é uma versão
alpha: reporte problemas informando Windows, dispositivo de áudio e passos.

## English

First public prerelease for validation. The portable Windows package includes
the application, NAM runtime, and Git-tracked examples under `samples/`.

Available in this version:

- offline IR and compatible NAM A2 Full/Lite and legacy capture auditioning;
- `DI → NAM → IR` chain with independent bypass controls;
- libraries, search, favorites, ratings, notes, and persistent preferences;
- NAM gain, master gain, peak meter, transport, and Loop;
- organized favorite capture and IR export;
- Portuguese and English interface;
- maintainer-tested Windows package, currently unsigned.

Extract the complete ZIP before running `AuditionManager.exe`. This is an alpha
release: report problems with Windows version, audio device, and reproduction steps.
